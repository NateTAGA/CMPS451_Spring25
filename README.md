# Handwriting Recognition Using Hidden Markov Models (HMM)

The purpose of this assigment was to: 
implement a handwriting recognition AI algorithm using Hidden Markov Models (HMM) and select an appropriate dataset for testing
This branch contains: 
python file( main.py) and a screenshot of the output in the termninal
 
 Project Overview

- Recognize handwritten digits (0–9) using HMMs.
-  Train one HMM per digit using extracted sequential features from image slices.
-  Dataset: [MNIST](https://www.openml.org/d/554) (loaded via `fetch_openml`)

 Tools and Libraries

- Python 3
- `hmmlearn`
- `numpy`
- `scikit-learn`
- `joblib`
- `matplotlib` (optional)
- `pandas` (required for loading MNIST)
